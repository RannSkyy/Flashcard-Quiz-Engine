# 🧠 Text-Based Quiz & Flashcard Machine

A simple Python application that combines an interactive quiz system with flashcards, helping users test their knowledge while reinforcing learning through active recall.

## ✨ Features

- 🎯 Interactive multiple-choice quiz
- 📚 Text-based flashcards
- 🔀 Randomized question order
- 🏆 High score tracking
- 📈 Learning progress summary
- 💾 High score saved locally
- 🖥️ Simple terminal interface
- 🚀 Easy to customize with your own questions and flashcards

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Clone this repository.

```bash
git clone https://github.com/your-username/text-based-quiz-flashcard-machine.git
```

3. Open the project folder.

```bash
cd text-based-quiz-flashcard-machine
```

4. Run the application.

```bash
python main.py
```
